# Vuelto Security Policy

## Reporting security vulnerabilities

If you find a security issue with Vuelto, please contact us privately via [email](mailto:dima@vuelto.pp.ua) instead of making a public issue or pull request. You will receive a response as soon as possible and will be notified and credited when a patch is released.

If email is not possible, please create a ticket on our [Discord server](https://vuelto.pp.ua/discord). If neither option is available, open a [GitHub issue](https://github.com/vuelto-org/vuelto/issues).

Thank you for helping keep Vuelto secure.

## Status

As of 13/11/2026, there are no known security issues with Vuelto.
